# 飞书笔记整理 Skill

把课程录音转写、会议记录、文章、课堂内容或学习资料整理成结构清晰、重点突出、可直接复制到飞书文档的中文笔记。

## 安装

将整个 `bijizl` 文件夹复制到 Codex skills 目录：

```text
~/.codex/skills/bijizl/
```

重新打开 Codex 会话后即可使用。

## 调用示例

```text
使用 $bijizl 整理下面这段课程录音转写：

【粘贴原始内容】
```

也可以直接提出“把这份会议记录整理成可复制到飞书的笔记”，由 Codex 自动匹配该 Skill。

## 包含内容

- `SKILL.md`：完整的笔记整理规则和输出结构。
- `agents/openai.yaml`：Codex 界面名称、简介和默认调用提示。
- `references/feishu-live-workflow.md`：飞书原位编辑、流程图与复习测试的操作规范。

本 Skill 默认保留信息完整度，纠正明显转写问题并重组知识逻辑。飞书原位编辑时，核心知识、重点提醒和易错点使用飞书原生高亮块；纯文本交付时使用独立引用块模拟。对无法确认或有争议的信息只做醒目标注，不自行编造。
